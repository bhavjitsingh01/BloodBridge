# Blood Request Feature Specification

## Objective
Allow users to request blood during emergencies.

## Functional Requirements
- User can create a blood request.
- User selects blood group.
- User enters hospital location.
- AI ranks nearby suitable donors.
- User receives donor details.

## Inputs
- Blood Group
- Hospital Location
- Units Required
- Emergency Level

## Outputs
- List of matched donors
- Estimated response time
- Priority score

## Success Criteria
- Response generated within 5 seconds.
- Only compatible donors are shown.
